Caso · Comparación de sensores binarios
DEUTSCH · 4 sensores, 2 pares independientes

¿Los sensores coinciden, por pares?

Cuatro sensores binarios (S1, S2, S3, S4), evaluados en dos pares independientes: S1–S2 y S3–S4. Cada sensor solo puede reportar 0 (normal) o 1 (alterado). De forma clásica, cada par se compara directamente (sensor_x == sensor_y). De forma cuántica, cada par se codifica como una función f dentro de un oráculo, y el mismo circuito de Deutsch —sin modificar— determina si esa función es constante (coinciden) o balanceada (difieren) con una sola consulta.
